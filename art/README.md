# art/ -- FloydFM

**Reference pictures, drawings, screenshots and source art for this plugin.**

Standard folder on every Zedtronics plugin (set 2026-08-11; backfilled fleet-wide
2026-08-12). Anything visual that a future session might need to SEE rather than
read goes here.

## What belongs here

- Reference photos of the hardware a panel is drawn from
- Sketches, mockups and layout drawings
- Screenshots dropped in for a session to look at
- Source art: square .ai / .png exports, logo lockups, panel captures
- Installer wizard art + .ico, generated by
  `python D:\Zedtronics\audacious\tools\make_installer_art.py <PluginKey>`
  (add this plugin's key to the tool's PLUGINS table if it has none yet --
  the tool reads the plugin's own title face and palette)

## What does NOT belong here

- Build artefacts. This folder is inputs and references (plus the generated
  installer art, which is committed so the .iss can reference it).
